# 욕구조사 사정도구 V0.3

이미지 기반 욕구조사 및 선호도 확인. 음성/AI 자동 생성 없음.

- 여행지 25, 음식 62, 간식 44, 활동 64개 (총 195개, 22개 중분류).
- 영역/중분류/페이지 전환 시 선택 유지. 기본 4개, 1/2/4/6/8/전체 보기.
- 현재 화면에 제시된 항목 수는 조사 완료를 뜻하지 않음. 미선택은 비선호가 아님.
- 시작 페이지 이름 입력, 전체 결과 재확인, TXT 로컬 다운로드. 결과 저장은 TXT만 지원하며 HWPX는 개발 범위에서 제외.
- 195개 항목 모두 640×640 WebP 실사형 이미지 연결. 이미지는 항목 고유 ID로 관리.
- 개인정보 및 결과는 브라우저 메모리에만 보관하며 GitHub에 업로드하지 않음. 새로고침 시 초기화.
- items.json의 image 및 imageStatus를 업데이트하여 이미지를 연동. 기존 images 폴더 유지.
- GitHub Pages main / root 배포. 로컬은 HTTP 서버로 실행.
