# 나의 선택 (V0.1)
이미지를 활용한 욕구조사 및 선호도 확인. 음성 및 AI 자동 생성 없음.

## 실행
Settings → Pages에서 main / root 배포를 설정합니다(계정 및 저장소 조건에 따라 사용 가능 여부가 다름). 로컬에서는 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 접속.

## 이미지 관리
images/에 이미지 파일을 추가하고 items.json에 고유 id, label, image 경로를 등록합니다. 기본 12개 SVG는 임시 그림 상징입니다.

## 제한
현재 선택 결과는 화면 상태에만 남고 영역 전환 또는 새로고침 시 초기화됩니다. 개인정보를 저장하지 않습니다. 비교·순차 제시 및 TXT/HWPX 저장은 후속 개발 대상입니다. 실제 장애인 대상 사용성 검증 전입니다.
